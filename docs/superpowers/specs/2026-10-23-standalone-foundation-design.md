# Standalone marketing foundation design
Approved scope: bootstrap Landing-Pages and package all four repositories independently, preserving existing ownership and production effects OFF.
Frontend choice: Vue 3 + TypeScript for Landing-Pages; existing React editors retained. This follows the current Linear architecture f2427ef9-6aa2-4837-829b-d3a295bdd471 (2026-10-23).
Public routes: /{en|es}/{landing|business}/{offering}, plus thank-you. First five offerings: hvac-heating, chimney-fireplace, insulation-weatherproofing, gutter-cleaning-repair, plumbing-winterization.
One public runtime registry maps exact hosts to approved public site documents. Unknown hosts fail closed. Browser workspace selection never authorizes a backend operation. Two sample brands are local preview fixtures, with separate host mappings.
Breero remains the owner of business records/publication. Its current public-submission schema lacks verified workspace/site binding. Deliver typed compatible requests, validated receipts, stable retry keys and preserved form state; server submission endpoints stay disabled pending that owner contract. Do not add a shadow database or fabricate accepted requests.
Editors get independent non-root container/static hosting with bounded same-origin proxy to the existing HTTPS gateway. Preserve PKCE and existing project payload shapes. Export an explicit saved authoring reference (workspace, project, kind, source revision) without tokens/content; it is not publication or execution authority.
Backend gets a non-root application image, dedicated development Compose stack, explicit migration command, health/readiness, operational counters without tenant/PII labels, backup/restore tooling tested only against disposable databases. No automatic schema mutation at application startup.
Every repository supplies source/CI/runbooks and branch-governance tests. No production activation, external delivery, fees, ads, message sends, existing database changes, or protected-branch direct development. Review and promotion remain separate from publication.
Acceptance: current-head lint/types/unit/browser/build/audit; container smoke; denial for unknown hosts, gateway failure and traversal; two public site contexts isolated; receipt only after durable backend acknowledgement; authorization regression suite; restore evidence; reviewed PRs. Runtime Keycloak/gateway and Breero ownership gaps remain explicit prerequisites.
